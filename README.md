# CDM → BA/BE → eCTD — Animated Pro Presentation

## What is included
- Reveal.js presentation
- Cinematic transitions
- Animated PK concentration–time graph
- Cmax / AUC / Tmax / t½ visual metrics
- BA/BE analysis workflow
- Interactive-style eCTD Module 1–5 architecture
- Traceability workflow
- Responsive layout

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and this README.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

GitHub will give you a public presentation URL.

## Important
This presentation is an educational visual framework. It intentionally avoids hard-coding jurisdiction-specific acceptance criteria or claiming that every study follows the same regulatory pathway.
